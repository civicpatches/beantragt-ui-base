# Reporting security vulnerabilities

Security vulnerabilities are reported confidentially to Civic Patches GmbH. Private vulnerability reporting is available under **Security** in the relevant repository when enabled. A confidential channel for technical details can also be requested through the Civic Patches contact page.

A report includes the release, the affected component, the impact and reproduction steps using synthetic data. Reports omit credentials and personal data. [Contact Civic Patches](https://civic-patches.de)
